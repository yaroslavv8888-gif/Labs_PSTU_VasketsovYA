      float: делит ошибочные 384 на 300 => результат 1.27999985218048 (из-за нехватки бит памяти)

   1. Введите m: 1
      Введите n: 2
      Результат n++ * m = 2 // участвует n = 2 и m = 1, дальше становится n = 3, результат 2 * 1 = 2
      Результат n++ < m = 0 // участвует n = 3 и m = 1 так как 3 < 1 результат 0 (ложь)
      Результат m-- > m = 1 // участвует m = 1, потом m становится m = 0 => 1 > 0 результат 1 (истина)
   2. Введите m: 3 
      Введите n: 2
      Результат n++ * m = 6 // участвует n = 2 и m = 3, дальше становится n = 3, результат 2 * 3 = 6
      Результат n++ < m = 0 // участвует n = 3 и m = 3 так как 3 < 3 результат 0 (ложь)
      Результат m-- > m = 1 // участвует m = 3, потом m становится m = 2 => 3 > 2 результат 1 (истина)
