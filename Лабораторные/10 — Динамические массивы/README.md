# Лабораторная работа №10 — Динамические массивы

## Вариант 4

Сформировать одномерный массив. Удалить из него элемент с заданным номером, добавить K элементов, начиная с заданного номера.

Номера элементов отсчитываются с единицы. Позиция вставки задаётся для массива после удаления. При позиции, равной исходному размеру, новые элементы добавляются в конец. Итоговый размер: `n - 1 + K`.

## Функции

- `Form` выделяет память и заполняет массив псевдослучайными числами от −49 до 50.
- `Print` выводит элементы.
- `Delete` освобождает память и обнуляет указатель.
- `Change` удаляет элемент и вставляет новые элементы, выделяя массив нужной длины.

## Проверка

Сборка C++17 с `-Wall -Wextra -Wpedantic -Werror` прошла без предупреждений. Проверены 182 сочетания удаления и вставки при исходных размерах от 1 до 6, а также отклонение 10 вариантов ошибочного ввода. Блок-схема загружена без проверки.
