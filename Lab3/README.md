# Лабораторная работа №3, вариант 4

Вычисление функции через разложение в степенной ряд. Код программы: `Lab3.cpp`.

## Задача

Функция `y = x * arctg(x) - ln(sqrt(1 + x^2))`, `x` от `0.1` до `0.8` с шагом `h = (b - a) / k`, `k = 10`.
Посчитать через ряд двумя способами и сравнить с точным значением `Y`:

* `SN` для заданного `n = 10`
* `SE` для заданной точности `E = 0.0001`

Ряд: `x^2/2 - x^4/12 + ... + (-1)^(n+1) * x^(2n) / (2n * (2n - 1))`

## Математическая модель

* `a`, `b` - границы `x`; `n` - число слагаемых; `k` - число шагов
* `st` - текущая степень `x` (`x^2`, `x^4`, ...), `zn` - знак слагаемого, чередуется
* `X` - значение на шаге; `SN`, `SE` - суммы ряда; `Y` - точное значение

Внешний цикл, действует пока `j <= k`:

1. `x = a + j * h;` для вычисления `X` на каждом шаге
2. Внутренний цикл `for`, ровно `n = 10` раз: `SN += zn * st / (2 * i * (2 * i - 1));`
3. Перед вторым циклом сбрасываем `zn = 1`, `st = x * x`, `i = 1`
4. Цикл `do while`, действует пока `fabs(res) >= E`:
   `res = zn * st / (2 * i * (2 * i - 1));` и `SE += res;`
5. После каждого прохода `st = st * (x * x)`, `zn = -zn`, `i++`
6. `Y = x * atan(x) - log(sqrt(1 + x * x));` для сравнения
