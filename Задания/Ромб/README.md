# Ромб в квадратной матрице

[Исходный код](romb.cpp)

Программа читает размер `d`, создаёт динамическую матрицу и печатает ромб: границу из единиц, внутреннюю область из нулей, снаружи — пробелы. В массиве внешняя область обозначена числом `6`.

## Формулы ромба

Индексы `i` (строка) и `j` (столбец) начинаются с нуля. Для полного симметричного ромба задаётся нечётный положительный размер `d = 2c + 1`, где `c = d / 2` — целочисленное деление, центр `(c, c)`.

Расстояние до центра по строкам и столбцам:

```cpp
int dist = abs(i - c) + abs(j - c);
```

| Область | Формула | Вывод |
|---|---|---|
| Граница ромба | `abs(i - c) + abs(j - c) == c` | `1` |
| Внутри ромба | `abs(i - c) + abs(j - c) < c` | `0` |
| Снаружи ромба | `abs(i - c) + abs(j - c) > c` | пробел |

Четыре стороны границы описываются уравнениями `i + j = c`, `i - j = c`, `j - i = c`, `i + j = 3c` в пределах матрицы `0 ≤ i, j ≤ 2c`.

### Диагонали ромба

Диагонали соединяют противоположные вершины:

- Вертикальная: `j = c`, от `(0, c)` до `(2c, c)`.
- Горизонтальная: `i = c`, от `(c, 0)` до `(c, 2c)`.

Обе диагонали содержат по `2c + 1 = d` позиций матрицы; расстояние между крайними позициями в единицах шага сетки равно `2c = d - 1`. При нумерации строк и столбцов с единицы их уравнения: `j = c + 1` и `i = c + 1`.
