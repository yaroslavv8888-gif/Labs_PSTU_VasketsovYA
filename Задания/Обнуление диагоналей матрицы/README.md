# Обнуление диагоналей матрицы

Программа создаёт динамическую квадратную матрицу заданного размера, заполняет её псевдослучайными числами и обнуляет главную и побочную диагонали. Выводятся исходная и изменённая матрицы.

[Исходный код](main.cpp)

## Проверка текущей версии

Память освобождается в правильном порядке: сначала все строки матрицы с индекса 0, затем массив указателей `M`.

Сборка C++17 с `-Wall -Wextra -Wpedantic -Werror` прошла без предупреждений. Для размеров 0, 1, 2, 3, 5 и 10 проверены нормальное завершение программы, обнуление обеих диагоналей и сохранение остальных элементов. Отрицательные размеры и нечисловой ввод не проверялись.
