# Обнуление диагоналей матрицы

Программа создаёт динамическую квадратную матрицу заданного размера, заполняет её псевдослучайными числами и обнуляет главную и побочную диагонали. Выводятся исходная и изменённая матрицы.

[Исходный код](main.cpp)

## Известная ошибка текущей версии

В конце программы `delete[] M` вызывается до удаления строк. Затем выполняется обращение к освобождённому `M[i]` и повторное `delete[] M`. Кроме того, цикл освобождения строк начинается с индекса 1 и пропускает строку 0.

Сборка C++17 прошла, но запуск с размером 2 завершился аварийно при освобождении памяти. Исходник сохранён без исправлений.
