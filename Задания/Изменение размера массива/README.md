# Изменение размера массива

Исходный динамический массив содержит `0 1 2 3 4`. Программа запрашивает новый размер и создаёт массив соответствующей длины: при уменьшении сохраняет начало, при увеличении заполняет новые элементы нулями. Память исходного массива освобождается.

[Исходный код](main.cpp)

## Примеры

| Новый размер | Результат |
|---|---|
| 3 | `0 1 2` |
| 5 | `0 1 2 3 4` |
| 7 | `0 1 2 3 4 0 0` |

Сборка C++17 прошла без предупреждений. Проверены размеры 0, 3, 5 и 7. Отрицательный размер и нечисловой ввод не проверялись.
